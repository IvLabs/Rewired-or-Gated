Three claims

We phrase the question as a binary — does tuning rewire the circuit, so that a largely new set of heads becomes critical, or merely gate it, so the same heads get reweighted? Five independent methods converge on gating.

C1 — Gating, not rewiring

The same heads, in the same roles, wired in largely the same way, carry the decision. Node overlap between base and instruct sits at J = 0.60–0.82.

C2 — Memory-ward robustness

Tuning pushes behaviour towards parametric memory. Instruct models reject a terse counterfactual far more than base ones — the opposite of naive user-following. The effect vanishes when the falsehood is written well.

C3 — Localization preserved

Conflict heads stay in the upper half of the network in both variants. The median conflict-head layer moves by at most two layers.

What gating looks like

A rewired circuit would recruit different heads. A gated one keeps the roster and turns the faders. Below is the claim as a diagram — head identity, role and layer position are preserved across tuning; the only thing that moves is how loudly each head pulls.

Skepticism you can write around

Instruction tuning produces a large behavioural change, but not the one the naive prior predicts. On the terse substitution conflict, contextual reliance drops in all three families: instruct models are markedly more likely to reject the injected falsehood and fall back on what their weights already say.

That is the calibrated response, not disobedience — the injected context is false. But the skepticism is a property of framing, not of trust. Deliver the same falsehood as a fluent, evidential passage and the base–instruct gap nearly disappears; both variants follow it at 0.88–1.00.

The robustness that tuning buys is real but narrow. It defends against one-line prompt injection and does nothing against well-written misinformation.

Five views, one verdict

No single attribution method is decisive. Node screens are cheap but correlational; edge methods see wiring but not causation; superposition sees function but not location; path patching only corroborates the node screen. Causal ablation is the one interventional test, and only for the heads it targets. So we triangulate.

Node attribution — LDS

A first-order logit-derivative saliency for every (layer, head) against the contrast target L = logitctx − logitmem. A head scores highly when a small change in its output slides the model between the context and memory answers.

Edge attribution — EAP-IG

Edge attribution patching with integrated gradients over the full 87k–390k edge graph, five integration steps. Run on the terse form only: the coherent passage repeats the distractor, which breaks EAP-IG's prefix/suffix alignment.

Superposition index

Each head gets a role on a continuum from pure memory to pure context, computed from an independent direct-logit-attribution pull ratio. Only 2–3 heads per family flip role across tuning; mean drift is near zero and slightly memory-ward.

Path patching & causal ablation

PH3-style path patching cross-checks the LDS ranking on the top-20 heads (Spearman 0.62–0.85, positive in all six cells). Ablation then amplifies or suppresses the selected heads and re-measures CRR against an a-priori sign.

S = ctx_pull − mem_pull|ctx_pull| + |mem_pull| ,  S ∈ [−1, 1]

+1 marks a pure context head, −1 a pure memory head, and the middle of the range is superposition: one head doing both jobs at once.

Six interventions across six model variants. Suppressing context heads drives contextual reliance down; amplifying them drives it up; suppressing memory heads drives it up. Every cell matches the sign we predicted in advance (binomial p ≈ 2⁻³⁶).

ΔCRR after each intervention. The circuit is sparse and asymmetric — suppressing just the five top context heads collapses context-following in the base models, while the five memory heads move CRR far less. Ablating an equal number of random late-layer heads moves CRR by −0.03 to +0.02, so the effect belongs to the heads LDS selects, not to poking late attention in general.

Why it matters

Because the conflict circuit is preserved rather than rebuilt, mechanistic tools calibrated on a base checkpoint — head-level steering, pruning methods such as PH3, superposition probes — should carry over to the deployed instruct sibling. Safety and interpretability work can be done on the cheaper, openly released base model and still describe the shipped one.

For retrieval and agent pipelines, the practical reading is narrower than it first appears. Instruct models resist terse, unsupported counterfactuals — a common injection pattern — yet remain fully persuadable by a fluent false passage. The vulnerability moves rather than closes. The same skepticism can also under-trust a legitimate but tersely stated retrieved fact, which can be mitigated either by elaborating the evidence or by intervening directly on the context heads.

Limitations

  • Scale. Experiments cover 3–4B models. Whether gating holds at substantially larger scale is open.
  • Substitution-only edges. The coherent behavioural effect has a node-level but no edge-level mechanistic counterpart.
  • Metric scope. Facts are restricted to single-token answers under each model's own tokenizer; CRR is a next-token measure, so multi-token and free-generation following are out of scope.
  • Single corpus. Four relation domains, all derived from ParaConflict. A naturally occurring conflict corpus and held-out-domain attribution remain future work.
